# BrizSolution Technology — Corporate Portfolio

Premium, responsive static website built with **HTML, CSS and vanilla JavaScript**. Prepared using the supplied 18-page BrizSolution Company Overview PDF. The company URL was also supplied; its live page did not expose readable page content during preparation, so factual company details in this version are based primarily on the PDF.

## Files
- `index.html` — portfolio content and structure
- `styles.css` — responsive premium design
- `script.js` — mobile navigation and dynamic copyright year
- `assets/Brizsolution-Company-Overview.pdf` — supplied company profile, linked as a downloadable PDF

## Preview
Open `index.html` in a modern browser. Google Fonts are loaded online; the site itself is static and requires no build process.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `brizsolution-portfolio`.
2. Upload the contents of this folder (not the outer folder itself) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

To use `www.solutionbriz.com`, configure the custom domain in GitHub Pages and update the DNS records at your domain provider as instructed by GitHub. Do not change the live domain's DNS until you are ready to publish and have checked the deployment.

- Partner, certification, security and compliance claims before adding certification or partner badges.
- Office address, phone and email are current.
- Replace the text-based “B” mark with the official company logo if available.
